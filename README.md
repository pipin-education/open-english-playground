**#🌈 Open English Playground**

An open-source interactive English learning platform designed for young learners.

## About the Project

Open English Playground is a beginner-friendly educational project that aims to make English learning more engaging through simple interactive activities.

The platform is designed for young learners, especially children aged 4–6, with Indonesian instructions and English learning materials.

## Learning Modules

The project is planned to include:

- 🎨 Colors — Learn basic color vocabulary.
- 🔢 Numbers — Practice counting from 1 to 10.
- 🐾 Animals — Discover animal names and sounds.
- 👋 Greetings — Learn simple everyday expressions.

## Current Features

- Interactive color vocabulary quiz.
- Automatic answer feedback.
- Simple and child-friendly interface.
- Responsive page layout.

## Technology

This project uses:

- HTML
- CSS
- JavaScript
- GitHub Pages

No installation is required to try the published website.
